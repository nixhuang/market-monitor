- **DEMO 投影大坑（记牢）**：往产物 index.html 注入 CSS **不能插入成对的 `<style>…</style>`**——

  正确做法：**只插入 CSS 文本**到最后一个 `</style>` 之前（rfind），或直接用 playwright 的 add_style_tag。
