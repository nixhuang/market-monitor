## 15:30 用户新诉求：保存不要触发重跑

「有没有一种方式，让页面挂一个不重新推送的页面，只记录计算持仓，保存只存进去而不重新运算抓取」。

**推荐方案：浏览器本地存储（localStorage），纯前端闭环**
- 首页加一个默认折叠的「持仓录入」面板：每只持仓一行「成本价 / 数量」→ 写 localStorage。
  **0 提交、0 Actions、0 等待**，改完即时刷新；Actions 每天重跑生成新 index.html 也不会冲掉（数据在浏览器）。
- 展示侧同样纯前端：页面加载后 JS 从位置条 `aria-label`（已含 低/本轮价/高）解析 + 读 localStorage
  → 注入黄色竖条、名称下的成本价与盈亏、顶部总市值/总盈亏/占比。
- 顺带比写 holdings.json 更私密（成本+数量根本不出浏览器）。
- 已知代价：换设备/清缓存会丢 → 补「导出 JSON / 导入 JSON」按钮做备份与跨设备搬运。
- 备选（不推荐）：daily.yml 的 push 触发加 `paths-ignore: ['holdings-private.json']`，提交该文件不跑 Actions；
  但仍要 token、仍在公开仓库，且要等下次跑或用 JS 动态 fetch 才显示。
- **关键发现（决定方案可行性）**：`daily.yml` 的 push 触发是 **paths 白名单**
  （只监听 holdings.json / settings.json / monitor.py / policy_alerts.py / earnings_sources.py /
  official-earnings.json / groups.json / 自身）——
  **只要把成本/数量写到白名单外的独立文件，就天然不会触发行情重跑**，连 paths-ignore 都不用加。
  `ensure-morning.yml` 只有 schedule+dispatch，不受影响；`tests.yml` 是 paths-ignore(index.html,status.json)，
  写新文件**会触发一次测试**（不抓取、约几十秒，可接受；要彻底静默就在 tests.yml 的 paths-ignore 里加一行）。
- 定稿方案：日常用 localStorage（即时、0 重跑）；跨设备靠手动「上传／拉取」两个按钮读写独立文件
  `position-costs.json`，复用 edit.html 的 GitHub 令牌（localStorage `mm_gh_token_v1`，Contents: Read and write），
  不用重新登录。上传到仓库 = 公开（成本+数量=市值），但上传是**可选**动作，不同步就永远只在本地。
  风险：两台设备都改过会互相覆盖 → 上传/拉取前显示双方时间戳让用户判断。
- 状态：**待用户拍板是否开工**（他还在构思成本价 UI，这批最好一次性设计完再改）。

## 15:58 澄清 + 关键查证：不上传能不能显示？

- 用户疑问：「成本价存本地浏览器的话，页面中需要成本价的项目就无法显示吧？必须上传一次才行？」
- 答：取决于**谁来画**——
  - 服务端渲染（monitor.py 读 holdings.json 生成 HTML）：必须上传 + 等 Actions，这是现有其它数据的方式；
  - **前端注入（本地方案）**：在你填的那台设备上**立刻显示**，上传只用于同步到别的设备。
  即"同一台设备永不上传也能看；换设备才需要上传一次 + 另一台拉取一次"。
- **关键查证（决定能否做得更省事）**：GitHub Pages 是**直接从 main 分支根目录发布**的
  （edit.html / run-status.js / manifest 都能在 https://nixhuang.github.io/market-monitor/ 下直接访问），
  而 daily.yml 的 push 触发是 **paths 白名单**。
  ⇒ 把成本/数量写进白名单外的独立文件 `position-costs.json`：
  ① 推送**不会触发行情重跑**；② Pages 会自动把它发布成
  `https://nixhuang.github.io/market-monitor/position-costs.json`；
  ③ 页面加载时 JS `fetch()` 它 → **所有设备自动拿到数据，不用手动"拉取"**。
  代价：进公开仓库（用户已拍板无所谓）；新设备要等 Pages 部署约 1 分钟（不是 Actions 抓取）。
  注意 fetch 要加 `?v=<时间戳>` 破缓存（Pages 有缓存头）。
- **推荐组合**：localStorage 负责即时编辑与显示（0 提交）+ `position-costs.json` 负责跨设备（后台自动 fetch 合并，
  本地有未上传改动时打「未同步」标记）。两种存储都不会被 Actions 每日重跑冲掉。
