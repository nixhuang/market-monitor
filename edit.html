第 1 步 · 贴一次 GitHub 令牌

令牌保存在这台设备的浏览器，仅用于向 GitHub API 认证；本仓库的清单和看板是公开的，无令牌也能查看。
没有令牌？去 GitHub → Settings → Developer settings → Fine-grained tokens， 新建一个只管 market-monitor 这一个仓库的令牌，选择 Contents: Read and write（编辑保存）和 Actions: Read and write（立即重跑）。有效期按需要设置，不要分享令牌。
